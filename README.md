# Portfolio 2026 (React + Supabase + JavaScript)

1. `npm install`
2. Copy `.env.example` to `.env` and add your Supabase URL and anon key (optional; the site works without them).
3. Run `supabase/schema.sql` in the Supabase SQL editor.
4. `npm run dev`, then `npm run build` to deploy (Vercel, Netlify, GitHub Pages).

Edit your details in `src/data.js`. Projects and certifications are read from Supabase when connected.
